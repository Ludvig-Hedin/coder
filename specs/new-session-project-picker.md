## New session project picker

- Enlarged the active workspace path on the new-session start page.
- Split the path into a muted parent directory line and a larger repo name line.
- Added a project picker dropdown beside the repo name so users can switch repos before starting a session.
- The picker lists known projects, marks the active one, and includes an add-project action.
- Reused the existing project open flow so switching still routes to the selected project's new-session page.
