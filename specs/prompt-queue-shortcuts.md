# Prompt Queue Shortcuts

- Clicking the send button sends immediately.
- `Enter` queues a follow-up when session follow-up mode is `queue` and the session is busy.
- `Cmd+Enter` on macOS, or `Ctrl+Enter` on other platforms, sends immediately even when queueing is available.
- If queueing is not available, `Enter` sends immediately.
- Queued messages render between the AI task list and the prompt input.
- Queued messages support drag reorder, send now, edit, and delete actions.
